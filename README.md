# Prompt Lab

Персональная PWA-лаборатория промтов с локальной языковой моделью.

## Что умеет
- Генерировать профессиональные промты из описания задачи обычными словами.
- Задавать уточняющие вопросы, если информации не хватает.
- Анализировать промты с помощью локальной языковой модели.
- Извлекать повторно используемые правила и сохранять их в личную базу знаний.
- Применять подтверждённые знания при создании новых промтов.
- Работать без облачных AI API и без собственного backend.
- Экспортировать и импортировать локальную базу знаний.

## Локальная модель
Приложение использует WebLLM и WebGPU:
- Qwen2.5 0.5B Instruct — около 945 МБ, рекомендуемая начальная модель.
- Qwen2.5 1.5B Instruct — около 1,63 ГБ видеопамяти; нужна более мощная графика.

При первом запуске выбери модель и нажми «Загрузить ИИ». Первоначальная загрузка требует интернет. WebLLM сохраняет загруженные веса в браузерном кэше; повторный запуск обычно не требует скачивания всей модели заново. Если очистить данные сайта/кэш браузера, модель может потребоваться загрузить снова.

Для запуска необходим современный браузер с WebGPU. На некоторых телефонах WebGPU может быть недоступен или нестабилен — совместимость зависит от браузера, GPU и драйверов.

## Офлайн и данные
- Исходный код приложения и интерфейс публикуются как статический сайт GitHub Pages.
- После первой загрузки PWA кэширует интерфейс.
- После загрузки весов модели генерация выполняется на устройстве; запросы к облачным AI API не используются.
- Каждое устройство имеет собственную базу знаний. Для переноса используй экспорт/импорт JSON.

## Разработка
`npm install`
`npm run build`

GitHub Actions собирает Vite-приложение и публикует каталог `dist` в GitHub Pages.
