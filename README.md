# Prompt Lab

Автономная PWA для создания и изучения промтов.

## Возможности
- Конструктор запросов.
- Академия: анализ структуры вставленного промта и поиск полезных приёмов.
- Подтверждение и сохранение правил в локальную библиотеку знаний.
- Использование сохранённых правил при создании новых промтов.
- Практика с эвристической оценкой структуры.
- Светлая/тёмная тема, экспорт и импорт базы JSON.

## Публикация через GitHub Pages
Открой **Settings → Pages** и в разделе **Build and deployment** выбери **GitHub Actions**. Workflow из `.github/workflows/pages.yml` опубликует сайт.

## Офлайн
Первый запуск сайта нужен через HTTPS, чтобы браузер установил Service Worker. После первой загрузки интерфейс кэшируется и работает офлайн. У каждого устройства отдельная база; перенос знаний выполняется через экспорт/импорт JSON.

## Важно
Анализ в этой версии основан на локальных правилах, а не на большой языковой модели. Никакие промты не отправляются в облако. Локальную LLM можно подключить отдельным этапом, но её движок и веса модели потребуется загрузить отдельно.
